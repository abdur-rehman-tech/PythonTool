# 🛡️ Security Learning Tool (Python)

![Python](https://img.shields.io/badge/Python-3776AB?style=flat-square&logo=python&logoColor=white)

A command-line tool I built to learn the basics of web and network security testing.

## ✨ Features

1. **SQL injection checker**: sends common payloads and compares responses
2. **Port scanner**: multi-threaded TCP scanning
3. **Service detection**: identifies services on open ports
4. **SQLMap integration**: runs a local sqlmap install against a target URL

## 🚀 Usage

```bash
pip install requests
python Tool.py
```

## ⚠️ Disclaimer

For **educational use and authorized testing only**. Practice on intentionally vulnerable targets such as `testphp.vulnweb.com` or your own labs. Never scan or test systems without permission.
